## 🧭 Sobre mim

```yaml
nome:       Rivadávia Neto
função:     Desenvolvedor Full Stack
foco:       sistemas escaláveis, automação e produtos SaaS
stack:      Python/Django · PHP · TypeScript · PostgreSQL · Docker · Linux
ambiente:   VPS própria (Ubuntu ARM), nginx, gunicorn, deploy por script
estudando:  arquitetura de software · SaaS · integração de IA · microsserviços
princípio:  código que outra pessoa entende em seis meses vale mais que código esperto
```

Trabalho de ponta a ponta: modelagem de dados, back-end, interface, infraestrutura e
deploy. Gosto de resolver o problema no lugar certo — banco no banco, regra no
servidor, e o mínimo possível de mágica no meio do caminho.

- 🎯 **Hoje:** reescrevendo um e-commerce de PHP para Django, com pagamento, estoque e painel próprios
- 🧩 **Me interesso por:** automação de processos, integração de IA em sistemas reais e APIs bem desenhadas
- 🤝 **Aberto a:** colaboração em projetos open-source, freelas e conversa técnica
- ⚡ **Curiosidade:** administro minha própria VPS — HTTPS, firewall, fail2ban e limite de requisição no nginx configurados à mão
